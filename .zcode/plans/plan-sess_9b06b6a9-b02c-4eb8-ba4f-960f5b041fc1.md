# План: 6 крупных улучшений VoxelFrame

## 1. Расширенная система сытости

**Player.cs:**
- Дополнительный расход голод при спринте: −1 каждые 5с активного спринта
- Расход при прыжках: −0.5 за прыжок (если голод > 2)
- Запрет спринта при голоде ≤ 2 (было ≤ 1)
- Увеличение времени поедания до 1.6с
- Анимация поедания: покачивание предмета в руке при EatTimer > 0

**GameData.cs:**
- Добавить BreadItem (хлеб, +5 сытости)
- Крафт-рецепт: 3 доски → 1 хлеб (сетка 1×3)

---

## 2. Расширенные пещеры

**WorldGenerator.cs → CarveCaves():**
- Увеличить порог коридоров: 0.11 → 0.18 (шире в 1.6×)
- Добавить третий шумовой канал для variation
- Горизонтальные залы (радиус 5-8 блоков)
- Ревайны: длинные разрезы (3-5 блоков шириной, 10-20 глубиной)
- Пещеры ниже y=30 не обрезать

---

## 3. Шейдер теней (упрощённый shadow mapping)

**WorldRenderer.cs:**
- Добавить `RenderTexture2D _shadowMap` (1024×1024)
- Добавить depth-only шейдер для прохода теней
- Каждый кадр: вычислить позицию солнца → сформировать light VP матрицу → пререндерить глубину → передать в основной шейдер

**Фрагментный шейдер:**
- Конвертировать мировую позицию фрагмента в light-space
- Сравнить глубину с shadow map
- Если фрагмент глубже → затемнить (shadow)

---

## 4. Экран загрузки

**Program.cs + GameSession.cs + Screens.cs:**
- Добавить `UiState.Loading` 
- При выборе мира: создать сессию с пустым миром → начать постепенную загрузку
- Каждый кадр: загружать 8 чанков + показывать прогресс
- DrawLoading(): чёрный фон + "Загрузка мира..." + прогресс-бар

---

## 5. Предмет в руке — позиция и размер

**Hud.cs:**
- Переместить из правого нижнего угла в центр-внизу (как Minecraft)
- Увеличить размер: 96px → 128px
- Позиция: `w/2 + 60, h - 138 + bob` (чуть правее центра)
- При EatTimer > 0: покачивание вверх-вниз

---

## 6. Пиксельный шрифт и улучшение графики

**Fonts.cs:**
- Программный пиксельный шрифт (8×8 на символ)
- ASCII + базовая кириллица (~80 символов)
- TextureFilter.Point для pixel-perfect

**TextureAtlas.cs:**
- Увеличить разрешение: 16×16 → 32×32 на тайл
- Перерисовать все тайлы с большим разрешением
